# 🦢 鹅鸭杀 记牌器 🦆

一个纯前端、单文件的《鹅鸭杀》(Goose Goose Duck)手游记牌辅助工具,主要面向 13 人轮抽局。打开 `index.html` 即可使用,数据全部保存在本机浏览器,无需联网。

## 功能

- **玩家追踪**:4~20 人可调,每人可标存活/出局、好人/坏人/中立、怀疑角色、行为备注
- **阵营人数配置**:默认 8 鹅 / 2 中立 / 3 鸭,实时显示各阵营还剩几个没找出来
- **轮抽顺序记录**:按手数记录谁选了什么,已选角色自动置灰防重复;选角色后自动给对应玩家标阵营色
- **真实角色库**:内置手游 S3 版鹅(19)/鸭(11)/中立(7)全角色名,可下拉选择
- **导出分享**:一键复制文本战报,或导出 PNG 战报图
- **AI 局势分析**:可配置任意 OpenAI 兼容接口(DeepSeek / OpenAI / Kimi / 通义等),根据标注给出抓鸭建议;API Key 仅存本机浏览器

## 使用

直接用浏览器打开 `index.html`,或访问已部署的网页链接。

## 部署

纯静态页面,任意静态托管(GitHub Pages / Netlify / Vercel / Cloudflare Pages)上传 `index.html` 即可。
